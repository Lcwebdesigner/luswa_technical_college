# Luswa Technical College - Official Website

> Skills for Today, Careers for Tomorrow | Kakamega, Kenya

A modern, responsive, and professional website for Luswa Technical College. Built to provide prospective students with information on admissions, courses, campus life, and student resources.

**Live Demo* https://lcwebdesigner.github.io/luswa_technical_college/
portfolio https://luswa-portfolio.vercel.app

### 🎓 About The College
Luswa Technical College (LTC) is a premier technical institution in Kakamega offering 30+ market-driven courses to 2500+ students, with modern facilities and industry-experienced faculty.

### ✨ Features
- Fully Responsive Design (Mobile, Tablet, Desktop)
- Modern Hero Section with Call-to-Action
- Courses Showcase (ICT, Business, Engineering, Hospitality)
- Admissions & Application Section
- Campus Life Gallery
- Contact Form & Location Map
- Clean UI/UX with Smooth Animations

### 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (Vanilla)
- Font Awesome Icons
- Google Fonts
